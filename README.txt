PinPilot Studio

Open index.html in a browser. It is a local-first Pinterest affiliate planning app.

Included:
- automatic or custom niche/board-topic idea generation
- 12 idea outputs with buying-intent scores, product search ideas, seasonal angles, audiences, and pain points
- product + affiliate-link pin package generator
- title, description, disclosure, keywords, image brief, overlay options, and A/B angle
- board builder with disclosure
- 12-month seasonal planner
- publishing quality checklist
- manual results tracker with title/image tags
- local browser storage and JSON export

Not included by design:
- Amazon login, search, scraping, or API connection
- image generation
- guaranteed income or automated publishing
